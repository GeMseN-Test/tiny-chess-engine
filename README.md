A 4,096-byte chess engine in Python: 0x88 board, negamax + alpha-beta, quiescence search, transposition table, killer ordering, piece-square tables and a fixed 80,000-node budget (deterministic, no clock). Practice Elo 1,609 mean over 3 trials (floor 1,154; house baseline ~1,365).

## Run it

```sh
python3 -P -s main.py
```
